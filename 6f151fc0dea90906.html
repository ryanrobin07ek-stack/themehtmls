Paystack API & Backend Integration Contract

This application strictly honors security guidelines: no secret API keys are ever stored or exposed in client-side code. In production, frontend transactions invoke the verified backend microservices below:
POST /api/paystack/initialize Server-Authoritative Total

Calculates exact stay or dining total from database inventory. Never trusts prices sent from the client. Calls https://api.paystack.co/transaction/initialize with the secret key on the backend.

POST /api/paystack/webhook HMAC SHA512 Signature Verified

Verifies x-paystack-signature with crypto.createHmac('sha512', PAYSTACK_SECRET_KEY). Updates booking status to 'CONFIRMED' only when charge event is verified.
