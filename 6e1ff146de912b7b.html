Paystack & Real Payment Configuration

This boutique integrates with Paystack for live luxury transactions across supported merchant currencies (NGN, GHS, ZAR, USD). In compliance with luxury e-commerce requirements, payment transactions are initiated via trusted channels and verified server-side.

Leave empty or use standard test keys. If no key is set, the boutique runs in transparent High-Fidelity Luxury Simulation Mode.

Required Production Backend Endpoints

  • POST /api/paystack/initialize — Initializes transaction with server-calculated order amount and returns transaction authorization URL & reference.
  • GET /api/paystack/verify/:ref — Queries Paystack API (https://api.paystack.co/transaction/verify/:reference) with Secret Key to verify receipt before marking order paid.
  • POST /api/paystack/webhook — Idempotent webhook receiver validating HMAC SHA512 signature against Paystack secret key.
