Important information about your code

Your recovery code is a temporary security credential. Treat it with the same care you would give other sensitive information used to access your account.

It expires after 10 minutes.

For security reasons, this code is valid for only 10 minutes after it is issued. Try to complete the verification process within that period.

It is intended for one use.

Once the code has been successfully used, do not expect it to work for another recovery attempt.

It belongs to your recovery request.

Use the code only in the official Craft recovery process that you initiated. Do not enter it into an unfamiliar website, send it in a message, or provide it to someone claiming they need it to help you.

A newer code may replace an older one.

If you request another code, use the latest code provided by the recovery process. If an earlier code no longer works, it may have expired or become invalid.

Never share it.

A person asking you to forward, read aloud, or send your recovery code may be attempting to gain access to your account. Keep the code private, even if the request appears urgent or comes from someone claiming to represent a support team.

What if your code doesn't work?

If the recovery process does not accept the code, there's no need to panic. A few simple checks may help you continue.

Check whether the code has expired.

If more than 10 minutes have passed since it was issued, return to the official Craft application and request a new code through the recovery process.

Check for typing errors.

Make sure every character is entered correctly. When copying the code, check that you haven't accidentally included a space or missed a character.

Make sure you're using the latest code.

If you've requested multiple codes, use the most recent one supplied for your current recovery attempt. Avoid switching between old emails and newer requests.

Return to the original recovery screen.

Enter the code in the intended field within the official Craft application. Do not submit it through an unfamiliar link or an unrelated website.

Try again through the official recovery process.

If the code has expired or is no longer accepted, follow the application's instructions to request a replacement.

Still having trouble?

If you've checked these details and continue experiencing problems, use the official Craft application or website to locate the appropriate support channel. Never send your password or recovery code when asking for help.

A few ways to protect your Craft account

Account security is not only about a single verification code. A few careful habits can also help reduce the risk of unauthorised access.

Keep your recovery information private.

Your email address and other recovery methods can be important parts of restoring access to an account. Keep them accessible to you and protected from unauthorised use.

Be careful with unexpected requests.

Do not trust a request simply because it sounds urgent or uses familiar branding. Verify unexpected instructions through an official Craft channel.

Never disclose your password or verification codes.

Craft support will never ask you to reveal your password or recovery code to them. A legitimate recovery process should allow you to enter your code directly into the official application.

Use official access points.

When recovering an account, start from the official Craft application or website. Be cautious of links received through unexpected messages or from unfamiliar senders.

Review your account after recovery.

Once you regain access, take a moment to confirm that your account details and available security settings are as you expect them to be. If you notice unfamiliar changes, seek assistance through an official channel.

Keep control of your email account.

Because recovery messages are delivered to your inbox, protecting access to your email account is also important. Use a strong, unique email password and any additional security protections available to you.

These practices help you make informed decisions whenever you receive an account-related notification.
